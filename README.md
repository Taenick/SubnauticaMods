# SubnauticaMods

Personal collection of Subnautica mods (BepInEx plugins).

## Mods

- **[DeleteOnSight](DeleteOnSight/)** — Look at it, delete it. A debug/cleanup
  tool that removes whatever you're looking at (base pieces, vehicles,
  creatures, world objects), with an area-delete mode for things without
  collision. Base pieces and crafted items refund their materials; storage
  containers drop their contents first.

- **[FoundationsUnchained](FoundationsUnchained/)** — Unlocks foundation
  placement controls: 90-degree rotation while free-placing, extended base
  snap range, vertical offset control for stacking foundations at arbitrary
  heights, and a free-grid mode for staggered/offset layouts. Compatible
  with SnapBuilder.

- **[PrawnStorageModuleFix](PrawnStorageModuleFix/)** — Fixes a vanilla bug
  where additional Prawn Suit Vehicle Storage Modules beyond the first don't
  add any storage. Each module now correctly adds 16 slots, matching the
  wiki spec, with a scrollbar once capacity exceeds 64 slots. Compatible
  with Better Vehicle Storage.

See each mod's own `README.txt` for full installation, configuration, and
compatibility details. All mods require BepInEx 5.4.21 for Subnautica.
